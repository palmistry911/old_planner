# Планировщик задач

Простая программа-планировщик задач на Python с использованием консольного интерфейса и обработки ошибок. Программа позволит добавлять, просматривать, отмечать как выполненные, и удалять задачи.
Также написаны юнит-тесты, покрывающие основные функции.

## Основные функции:

  `add_task(description: str) -> bool:`
  
  Ввод: описание задачи (строка).
        
  Вывод: True, если задача была добавлена, иначе False (например, если строка меньше двух символов).

  `view_tasks():`
  
  Ввод: нет.
        
  Вывод: выводит список всех задач, с пометками о выполнении.

  `mark_task_completed(task_index: int):`
  
  Ввод: индекс задачи (целое число).
  
  Вывод: помечает задачу как выполненную, если она ещё не выполнена.

  `remove_task(task_index: int):`
  
  Ввод: индекс задачи (целое число).
  
  Вывод: удаляет задачу из списка.

  `save_to_file(filename="tasks.txt"):`
  
  Ввод: имя файла (строка).
  
  Вывод: сохраняет все задачи в файл.

### Использование:

1. Скачайте или клонируйте проект с GitHub.

2. Запустите программу с помощью команды: 

`python main.py.`

3. Введите команду в меню для добавления, просмотра, удаления или выполнения задач.

### Запуск тестов:

Для запуска тестов используйте команду:

`python -m unittest main_test.py`
